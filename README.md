# 🌸 日本語 단어장

일본어 단어 암기앱 (브라우저에서 바로 실행되는 단일 HTML 파일)

- **홈**: 오늘 외울 단어, 중요 단어, 복습(어제/3일/7일 전), 주간 진도율, 자주 틀린 단어
- **단어목록**: 요미가나/단어/뜻/예문/태그 추가·수정·삭제, 외움·중요 표시, 검색·필터·페이지
- **단어퀴즈**: 단어→뜻 / 뜻→단어 / 단어→읽기, 4지선다 또는 직접 입력
- 하단 유튜브 음악 바

단어 데이터는 각자 브라우저(localStorage)에만 저장됩니다. 기기를 옮길 땐 단어목록의 **백업 / 불러오기**를 사용하세요.

> 유튜브 음악은 `https://` 주소(GitHub Pages)로 열어야 재생됩니다. 파일을 직접 열면(file://) 유튜브가 재생을 막아요.
