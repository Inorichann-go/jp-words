# 🌸 日本語 단어장

일본어 단어 암기앱 (브라우저에서 바로 실행, 폰 홈 화면에 앱처럼 설치 가능)

- **홈**: 오늘 복습(자동 복습 일정), 오늘 외울 단어, 주간 진도율, 중요 단어, 자주 틀린 단어, 빠른 실행(카드·듣기·퀴즈)
- **자동 복습 일정**: 외운 단어를 1·3·7·14·30일 간격으로 다시 보여주고, 30일 복습을 통과하면 🏆 완전히 외움
- **플래시카드**: 뒤집어 확인 → 모름/헷갈림/앎 (키보드 1·2·3, 좌우 스와이프)
- **듣기 모드**: 단어 → 뜻 → 예문을 자동으로 계속 읽어주는 흘려듣기
- **단어목록**: 요미가나/단어/뜻/예문/태그 추가·수정·삭제, 한꺼번에 등록(엑셀·시트 붙여넣기), 왼쪽 태그 메뉴, 검색·필터·페이지
- **단어퀴즈**: 단어→뜻 / 뜻→단어 / 단어→읽기 / 듣고 뜻 / 예문 빈칸, 4지선다(헷갈리는 보기) 또는 직접 입력
- **하단 음악 바**: 유튜브 재생목록, 이전/다음 곡, 섞어 듣기, 반복, 이어 듣기
- **⚙ 설정**: 태그 관리, 백업/불러오기, 앱 설치 안내

단어 데이터는 각자 브라우저(localStorage)에만 저장됩니다. 기기를 옮길 땐 **⚙ 설정 → 💾 데이터**의 백업 / 불러오기를 사용하세요.

> 유튜브 음악과 앱 설치는 `https://` 주소(GitHub Pages)로 열어야 됩니다.
